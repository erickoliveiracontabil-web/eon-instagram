# eon-instagram

Imagens, vídeos e locuções públicas das publicações do Instagram [@eonsistema](https://www.instagram.com/eonsistema),
e as ferramentas que geram esse material. O Metricool busca os arquivos por aqui.
Nada do sistema EON fica aqui.

- `AAAA-MM-DD/`: peças de cada dia de publicação (stories, feed, reel).
- `locucao/`: locução de cada reel (voz Caio).
- `ferramentas/`: geradores das artes e dos reels, com fonte, logo e mascote em `ferramentas/assets/`.
- **[GUIA.md](GUIA.md)**: como continuar o trabalho (rotina, regras de conteúdo, voz, agendamento).
